Write a combinational Verilog module `crc16` that advances a CRC-16/CCITT checksum by one data byte. Inputs: `crc[15:0]` (current CRC) and `data[7:0]` (next byte). Output `next[15:0]`: the CRC after feeding `data` most-significant bit first, using the generator polynomial x^16 + x^12 + x^5 + 1 (0x1021), no reflection and no final XOR (the XMODEM/CCITT-FALSE update step). Fewer LUT4s and fewer logic levels are better.
