Write a synchronous Verilog module `rv32i_core`: a single-cycle RV32I processor core (base integer ISA, no M/A/C/F/CSR/FENCE/ECALL/EBREAK).
Ports: `clk`, `rst_n` (active-low synchronous reset); outputs `imem_addr[31:0]`, `dmem_addr[31:0]`, `dmem_wdata[31:0]`, `dmem_wstrb[3:0]`; inputs `imem_rdata[31:0]`, `dmem_rdata[31:0]`.
Memory interface (modelled by the testbench, asynchronous/combinational): `imem_rdata` is the instruction word at `imem_addr`; `dmem_rdata` is the aligned little-endian 32-bit data word at address `dmem_addr & ~3`. Stores are performed by the memory at the rising clock edge using `dmem_addr`, `dmem_wdata`, `dmem_wstrb` (byte enables, 0 = no store).
Behaviour: after reset (held low for at least one rising edge) pc = 0 and registers x1..x31 are 0 (x0 always reads 0, writes to x0 are discarded). In every cycle the core executes the instruction at `imem_addr = pc`: it reads rs1/rs2 from the register file, and at the rising edge writes rd (if the instruction writes one and rd != x0) and sets pc to the next pc. The instruction semantics are those of the `rv32i_exec` problem: LUI, AUIPC, JAL, JALR (target bit 0 cleared), the six branches, LB LH LW LBU LHU, SB SH SW (mem_wdata = rs2 << (8*addr[1:0]), mem_wstrb = (1/3/15) << addr[1:0]), the OP-IMM and OP instructions (SLLI/SRLI/SRAI need funct7 0000000/0000000/0100000; SUB/SRA need funct7 0100000; M-extension funct7 0000001 is illegal), all arithmetic mod 2^32.
An illegal instruction (any encoding not listed, including instr[1:0] != 2'b11, reserved funct3/funct7, FENCE/SYSTEM) or a misaligned load/store (LH/LHU/SH with addr[0] = 1, LW/SW with addr[1:0] != 0) acts as a NOP: no register write, no store (dmem_wstrb = 0), pc = pc + 4. A misaligned load/store still drives dmem_addr to the computed address.
Observed signals (compared every cycle, in the cycle in which the instruction executes, before the clock edge): `imem_addr` always; `dmem_wstrb` always; `dmem_addr` only for loads and stores (don't-care otherwise); `dmem_wdata` only when dmem_wstrb != 0 (don't-care otherwise). Reset may arrive at any time and restores pc = 0 and all registers to 0.
Fewer LUT4s and fewer logic levels are better. The testbench runs random programs; every instruction must behave exactly as specified.
