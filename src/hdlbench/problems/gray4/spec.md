Write a synchronous Verilog module `gray4` with inputs `clk`, `rst_n` (active-low, synchronous reset to count 0), `en` and output `q[3:0]`. A hidden binary counter increments by 1 on each rising clock edge where `en` is 1 (wrapping at 16); `q` is that count in Gray code (q = n ^ (n >> 1)). `q` must be registered state or a function of registered state only (it may not depend combinationally on `en`).
